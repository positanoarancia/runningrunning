# 러닝 페이스 계산기

## 소개
러닝머신 속도(km/h)와 러닝 페이스(min/km)를 빠르게 변환할 수 있는 모바일 중심 웹 도구입니다.
속도와 페이스를 직관적으로 전환하고, 현재 페이스 기준 예상 완주 시간도 함께 확인할 수 있습니다.

## 주요 기능
- 속도 ↔ 페이스 실시간 변환
- speed / pace 기준 전환
- 슬라이더 및 눈금 기반 조작
- `- / +` 버튼을 통한 미세 조정
- 10km / 하프 예상 완주 시간 표시
- 다크 / 라이트 모드 지원
- 공유 버튼 지원
- 모바일 최적화 UI

## 왜 만들었는가
러닝머신에서 운동할 때
- 11km/h가 몇 분 페이스인지
- 5:30/km가 몇 km/h인지
를 빠르게 확인하고 싶은 니즈를 해결하기 위해 제작했습니다.

기존 계산기 서비스들은 기능은 많지만 사용성이 떨어지는 경우가 많아,
더 빠르고 직관적인 UX를 목표로 설계했습니다.

## 타겟 사용자
- 러닝 입문자
- 러닝머신 사용자
- 목표 기록을 계산하고 싶은 일반 러너
- 속도와 페이스를 자주 변환하는 사용자
